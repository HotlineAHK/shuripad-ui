# shuripad-ui

Веб-страница настройки для шури-пада (прошивка и железо: https://github.com/HotlineAHK/shuri-pad).

Плата в режиме настройки при живом интернете скачивает эту страницу с GitHub Pages и раздаёт со своего IP (данные тянет с ручки `/api/state` самой платы). Нет интернета — плата отдаёт встроенную страницу из прошивки.

Правки публикуются автоматически: commit в `main` → Pages пересобирает → плата подтянет новую версию при следующем входе в режим настройки.
